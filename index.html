Como usar

Importe os 3 CSS de fundação + a biblioteca FDS. Sem build, sem framework — funciona em qualquer página HTML, incluindo WordPress.

<!-- 1. Fonts + tokens (3 CSS de fundação) --> <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Sora:wght@100..800&display=swap"> <link rel="stylesheet" href="css/tokens.css"> <link rel="stylesheet" href="css/base.css"> <link rel="stylesheet" href="css/components.css"> <link rel="stylesheet" href="css/molecules.css"> <!-- 2. Vendors --> <script src="https://cdn.jsdelivr.net/npm/motion@11/dist/motion.js"></script> <script src="https://unpkg.com/lucide@latest"></script> <!-- 3. Biblioteca FDS --> <script src="js/fds.js"></script> <script src="js/fds-theme.js"></script> <script src="js/fds-toast.js"></script> <script src="js/fds-clipboard.js"></script> <script src="js/fds-codeblock.js"></script> <script>lucide.createIcons();</script>

Cole no <head> do tema WordPress (ou em qualquer HTML). Tudo pronto — botões, cores, animações funcionando.
